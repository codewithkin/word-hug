Spec notes
Step indicator is a five-segment strip, current segment widened — position without a "4 of 5". Skip is a real tile-button, not grey text, and is absent on 5 and 8. Step 5 carries the puzzle skeleton exactly: context strip, clue stack, input + submit, reserved feedback line, utility bar.
Decisions taken
Tutorial answer is LIGHT — SUNLIGHT, MOONLIGHT, DAYLIGHT, so nobody can fail it. The reveal lives in the reserved feedback zone, so nothing moves when it appears. Reminder time is chosen before the OS prompt, so "Allow" asks once and lands.
